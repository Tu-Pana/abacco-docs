Abacco es el ERP contable chileno para gestoras y pymes: cartera de clientes,
F29, libros de compra/venta, balances, remuneraciones y cierre mensual con IA.
Esta documentación cubre las dos formas de integrarte:

<CardGroup cols={2}>
  <Card title="API de Abacco" icon="code" href="/api/introduction">
    API REST con autenticación por API Key: documentos tributarios, libros
    de compra/venta y remuneraciones.
  </Card>
  <Card title="Abacco MCP" icon="robot" href="/mcp/overview">
    Conecta Claude (u otro cliente MCP) a tu contabilidad: cartera, F29,
    balances y asientos, conversando.
  </Card>
</CardGroup>

## ¿Qué puedes construir?

- **Integraciones contables**: sincroniza documentos y libros del SII con tus
  sistemas internos.
- **Reportería propia**: consume balances, estado de resultados y libro mayor
  para tus dashboards.
- **Automatización de nómina**: consulta empleados, liquidaciones e
  indicadores previsionales del período.
- **Asistentes con IA**: con el MCP, tu equipo pregunta "¿cómo van los F29 de
  julio?" y obtiene la respuesta con datos reales, con permisos por usuario.
